Token da linha

Quem tem o token controla esta linha (ligar, atender, ouvir). Gerar um novo invalida o anterior e todos os iframes/integrações que o usam.

Receptor: toca em todos os atendentes; o primeiro a clicar em Atender fica na ligação

Discador: faz ligações por esta linha

Troque agent=Atendente pelo nome de quem usa a página (aparece para os outros atendentes e no histórico). O allow="microphone; autoplay" é obrigatório, e o site precisa estar em HTTPS para o navegador liberar o microfone. Para restringir em quais sites os iframes podem aparecer, use Configurações › Sites permitidos.

Integração por JavaScript (sem iframe)

        

          Para sites onde o iframe não funciona, ou para montar a interface do seu jeito. O SDK não desenha nada:
          ele avisa quando toca, atende, liga, desliga e cuida do áudio. O HTML/CSS é seu.
        

        

        

          
          
        

        
O exemplo é um telefone flutuante no canto da página, já com a URL e o token desta linha. Abra num site em HTTPS (ou localhost).

      


      

        
Eventos

        
phone.on("ready", (line) => …)              // conectado à linha
phone.on("line", (line) => …)               // status mudou (online, sem telefone…)
phone.on("incoming", (call) => …)           // ligação chegando (toca em todos)
phone.on("answered", (call) => …)           // você atendeu
phone.on("answered-elsewhere", (call) => …) // outro atendente atendeu antes
phone.on("dialing", (call) => …)            // ligação de saída iniciada
phone.on("connected", (call) => …)          // em ligação
phone.on("ended", (call) => …)              // encerrada (call.endReason)
phone.on("busy", ({ from }) => …)           // ligaram com a linha ocupada
phone.on("levels", ({ mic, remote }) => …)  // volume (0 a 1) para medidores
phone.on("message", (msg) => …)             // mensagem recebida ou enviada (msg.direction)
phone.on("message-status", (msg) => …)      // entregue / lida (msg.status)
phone.on("error", (err) => …)

Autenticação

        

          Envie Authorization: Bearer <token da linha> (ou ?token= em WebSockets).
          O token está na aba Iframes. Áudio: PCM16 little-endian, mono, 16 kHz.

Histórico e agenda do celular

        
Busca no celular as mensagens antigas de cada conversa (de 50 em 50, até o início) e os nomes
          salvos na agenda, que passam a aparecer nas conversas e na pesquisa. O celular precisa estar ligado e com internet; pode levar alguns minutos.

        

          
          
        

        
Conversas que nunca passaram pelo gateway só chegam ao vincular de novo (Desconectar telefone e ler o QR):
          o celular envia o histórico completo para um aparelho recém-vinculado.

      

      

        
Contatos ocultos · só administradores veem esta lista

        
Mensagens e ligações destes números continuam gravadas, mas não aparecem no painel, no atendimento,
          na API nem no webhook. O gateway não atende as ligações deles: tocam só no celular.

        
        
Um por linha, com DDI e DDD (com ou sem o 9º dígito). Também dá para ocultar pelo chat: Dados do contato › Ocultar este contato.

Ações da linha

        

          
          
          
        

        

          Desconectar telefone remove o aparelho do WhatsApp e mostra um novo QR (a linha e o token continuam).
          Excluir desconecta, apaga a linha e invalida o token.
